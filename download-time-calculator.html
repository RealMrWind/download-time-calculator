Why isn't it exact?

This gives a theoretical estimate. Actual downloads can take longer because of Wi‑Fi, network congestion, server limits and other overhead. Internet speeds are normally measured in bits per second, while file sizes are measured in bytes, so the calculator handles the conversion for you.
