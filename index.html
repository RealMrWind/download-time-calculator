How Long Does a Download Take?

Download time depends mainly on two things: the size of the file and the speed of your internet connection. A larger file takes longer to download, while a faster connection reduces the time required.

For example, a 100 GB game downloaded at 100 Mbps takes approximately 2 hours and 13 minutes under ideal conditions.

Actual download times can be longer because of Wi-Fi performance, network congestion, server limitations and other factors.

Why Is My Download Taking Longer?

The speed advertised by your internet provider is not always the speed you will see during an actual download.

Your real download speed can be affected by Wi-Fi signal strength, the number of devices using your connection, network congestion, the server providing the file and the performance of your computer or console.

For this reason, the calculator provides a theoretical estimate rather than a guarantee of the actual download time.

How the Calculator Works

Internet speeds are normally measured in megabits per second (Mbps), while file sizes are commonly measured in megabytes (MB) or gigabytes (GB).

There are 8 bits in one byte, so the calculator converts the file size into bits and divides it by your internet speed to estimate the download time.
